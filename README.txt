Rule-Based Ad Scheduler Prototype

Open index.html in a browser to review the clickable prototype.

Key interactions included in this version:
- Suggested rules can be applied, adjusted, disregarded, or regenerated.
- Rules can be reordered by drag-and-drop priority.
- Budget and bid changes use signed percentage fields with minus/plus step buttons. Reductions are capped at -100%.
- Campaign pause greys out budget/bid controls and shows as "Campaign paused" in the grid.
- Pause overlaps require an explicit decision: pause campaign or apply budget/bid changes.
- General overlaps require a decision: combine overlaps or resolve by priority.
- Save schedule is disabled while open warnings/checks remain.
- The rule payload can be shown for handoff discussions with developers.

Suggested external sharing: upload index.html to a GitHub repository and enable GitHub Pages from the repository's Pages settings.
